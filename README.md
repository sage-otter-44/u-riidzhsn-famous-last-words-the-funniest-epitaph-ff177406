# Famous Last Words: The Funniest Epitaph

A make.fun bounty entry: one line of famous last words, written as a tombstone epitaph.

## Entry

> I asked for my last words to be 'I told you I was sick.' They carved 'I told you so' instead.

93 characters, one line.

## How it works

`main.ts` (Node, no dependencies) writes the epitaph to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Before writing, it enforces the competition gate: 1–150 characters, a single line, not blank.

Run it with:

```sh
node main.ts
```
